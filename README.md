# oaqjp-final-project-emb-ai

## Emotion Detection Application

Final project for the IBM **Developing AI Applications with Python and Flask** course on Coursera.

## Project Name

**Emotion Detector** — AI-based web application for analyzing customer feedback.

## Description

This Flask application uses the IBM Watson NLP library to detect emotions (anger, disgust, fear, joy, sadness) in text and identify the dominant emotion.

## Technologies

- Python
- Flask
- IBM Watson NLP (Embeddable AI)
- Requests
- Unittest
- PyLint

## Run locally (IBM Cloud IDE recommended)

```bash
pip install flask requests pylint
python test_emotion_detection.py
python server.py
```

Open `http://localhost:5000` in your browser.
